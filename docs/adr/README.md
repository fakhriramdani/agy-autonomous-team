# Architecture Decision Records (ADR)

Direktori ini digunakan oleh **Lead Engineer** untuk mencatat setiap keputusan arsitektur penting yang diambil dalam proyek.

## Format File
Nama file menggunakan nomor urut 4 digit dan slug keputusan:
`docs/adr/0001-<judul-keputusan>.md`

## Kapan ADR Wajib Dibuat?
- Pemilihan database (misal: SQLite vs PostgreSQL).
- Pemilihan arsitektur auth (misal: JWT vs Session Cookie).
- Pemilihan library/state management besar.
- Strategi caching atau antrean background job.
- Perubahan arsitektur breaking / migrasi sistem.
